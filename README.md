# 会话清理 (session-cleanup)

给 DeepSeek Harness 侧栏加一个会话管理面板：按工作区整理会话，支持归档、回收站删除、备份/导入和对话记录查看。

## 功能

- 按工作区分组，组默认折叠，点组标题展开；子代理嵌套在父会话下，勾选父会话会级联选中子代理
- 归档 / 恢复：走 Harness 原生归档，文件保留、可逆
- 删除 = 移到回收站：默认保留 7 天（可改 1–365 天），期间可恢复；永久删除需二次确认
- 备份 / 导入：单会话、已选中或全部会话导出为 `.tar.gz`（会话日志 + 引用到的图片等附件），可导入到其他 DSH；导入时可选择目标工作区
- 查看对话记录：会话元数据 + 按轮次折叠的提问记录，颜色区分提问/回复
- 移动端行操作收进「更多」菜单；侧栏会话「···」菜单里也可删除

## 使用

1. 侧栏点「会话清理」进入面板
2. 勾选会话后，底部可归档、恢复、备份或删除
3. 删除的会话进入「回收站」，可恢复或永久删除，也可一键清空
4. 工具栏「备份」打开备份/导入弹窗：导出全部、或选择备份文件导入
5. 每行「查看」打开对话记录；移动端用「更多」展开行操作

## 安装

用插件管理器安装：

```
git+https://github.com/ming-a1/session-cleanup.git
```

或在插件广场（Discover）添加索引后搜索「会话清理」：

```
https://raw.githubusercontent.com/ming-a1/session-cleanup/main/plugin-market.json
```

安装 / 更新后需要重启 `dsh web`。

## 注意

- 运行中的会话不能删除或移动；仍在内存中的会话需要重启 `dsh web` 后才能移动
- 仅适配 JSONL 会话后端；不符合预期时删除会安全中止，不会误删
- 导入文件上限 64 MB（含附件）；备份不含回收站、归档和置顶状态
